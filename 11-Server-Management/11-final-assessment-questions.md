# Final Assessment Questions

> ℹ️ **Advanced – not part of the exam.** Chapter 11 is a look ahead for students who want to go further. You do **not** need to know this material for the *Introduction to Linux* exam. The follow-up course **Linux Server Management** covers these topics in depth.


1. Design a backup strategy for a small business server
2. Create a script to monitor system health and send alerts
3. Explain how you would secure a new Linux server
4. Describe the process of troubleshooting high CPU usage
5. Design a user management system for a development team
6. Create a maintenance schedule for a production server
7. Explain how to implement log rotation and management
8. Design a file permission strategy for a shared project
