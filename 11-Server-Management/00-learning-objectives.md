# Learning Objectives

> ℹ️ **Advanced – not part of the exam.** Chapter 11 is a look ahead for students who want to go further. You do **not** need to know this material for the *Introduction to Linux* exam. The follow-up course **Linux Server Management** covers these topics in depth.

- Master process management and system monitoring
- Understand system services and job scheduling
- Learn network basics and system maintenance
- Implement backup and recovery strategies
- Integrate all Linux skills learned in previous lessons
- Prepare for real-world Linux administration tasks
