# Learning Objectives

After this lesson you can:

- Explain users, groups, UIDs and GIDs, and the difference between root, system and regular users
- Read the files `/etc/passwd`, `/etc/shadow` and `/etc/group`
- Create, modify, lock and delete users (`useradd`, `usermod`, `passwd`, `userdel`)
- Create groups and add users to them, without accidentally removing them from other groups
- Use `sudo` and `su` to work with administrator rights
- Check who you are and which groups you belong to (`id`, `groups`, `whoami`)

> ℹ️ Sections and blocks marked **ℹ️ Advanced** are optional on a first read.
