# Summary: Lesson 9 – Users & Groups

**Concepts**
- User types: root, system, regular users
- UID, GID, primary vs secondary groups
- Files: `/etc/passwd`, `/etc/shadow`, `/etc/group`, `/etc/sudoers`
- sudo & privilege escalation, `sudo` group
- User environment & startup files (`/etc/skel`, `~/.bashrc`, `~/.profile`)
- User security & auditing

**Commands**
- Info: `id`, `groups`, `whoami`, `who`, `w`, `last`, `getent`
- Users: `useradd` (`-m`, `-s`, `-G`), `usermod` (`-aG`, `-L`, `-U`), `userdel` (`-r`), `passwd`, `chage`
- Groups: `groupadd`, `groupmod`, `groupdel`, `gpasswd`
- sudo: `sudo`, `visudo`, `su`
- Profile: `chsh`, `chfn`
