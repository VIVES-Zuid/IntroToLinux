# Summary: Lesson 10 – Permissions & Tools

**Concepts**
- Permission string: file type + user/group/other `rwx`
- Effect of `rwx` on files vs directories
- Symbolic (`u+x`, `g-w`, `o=r`) and octal (`755`, `644`) notation
- Ownership: user & group
- Special bits: SUID (4000), SGID (2000), sticky bit (1000)
- Default permissions with umask
- Principle of least privilege

**Commands**
- `ls -l`, `chmod` (`-R`), `chown` (`user:group`), `chgrp`
- `umask`
- `find` (`-name`, `-type`, `-size`, `-user`, `-perm`, `-mtime`, `-exec`, `-delete`)
- `locate`, `updatedb`
- `date`, `cal`, `sleep`, `time`
