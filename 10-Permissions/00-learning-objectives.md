# Learning Objectives

After this lesson you can:

- Read a permission string like `-rwxr-xr--` and explain what it allows
- Explain the difference between `r`, `w` and `x` on a **file** and on a **directory**
- Change permissions with `chmod`, in symbolic (`u+x`) and numeric (`755`) notation
- Change the owner and group with `chown` and `chgrp`
- ℹ️ *Advanced (optional):* recognise the special bits SUID, SGID and the sticky bit in `ls -l`
- Explain how `umask` determines the permissions of new files
- Find files by name, type, size, time, owner and permissions with `find`
- Use some handy system tools: `locate`, `date`, `cal`, `sleep`, `time`

> ℹ️ Sections and blocks marked **ℹ️ Advanced** are optional on a first read.
