# Summary: Lesson 2 – The Shell

**Concepts**
- TTY, terminal, console, shell
- Shell types (bash, zsh, …) & the prompt
- User types: root, regular, system users
- File system hierarchy (FHS), root directory `/`
- Absolute vs relative paths, `.` `..` `~` `-`
- Home directory (`/home/<user>`)
- Permissions basics: `r` `w` `x`
- man page sections & navigation (`/`, `n`, `q`)

**Commands**
- Users: `su`, `sudo`, `who`, `w`, `whoami`
- Navigation: `pwd`, `cd`, `ls` (`-l`, `-a`)
- Files: `touch`, `mkdir` (`-p`), `cp` (`-r`), `mv`, `rm` (`-i`, `-r`, `-f`), `rmdir`
- Viewing/editing: `cat`, `less`, `nano`
- Download: `wget`
- Help: `man`, `apropos`, `--help`
