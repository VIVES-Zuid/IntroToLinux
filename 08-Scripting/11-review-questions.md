# Review Questions

1. What is the purpose of the shebang line in a script, and on which line must it be?
2. How do you make a script executable, and why do you type `./` in front of its name?
3. What's the difference between `$1`, `$#` and `$@`?
4. How do you read user input in a script?
5. Why does `if ["$age" -gt 18]` give an error? Write it correctly.
6. When would you use a `while` loop instead of a `for` loop?
7. What does `exit 1` mean, and how can you see the exit code of the last command?
