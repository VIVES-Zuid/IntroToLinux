# Learning Objectives

After this lesson you can:

- Write a script with a shebang line, make it executable and run it
- Use variables, command substitution `$( )` and simple arithmetic `$(( ))`
- Ask the user for input with `read`
- Use command-line arguments `$1`, `$2`, `$#` and `$@`
- Make decisions with `if` / `elif` / `else` and the test command `[ ]`
- Repeat work with `for` and `while` loops
- Build a simple menu with `case`

> ℹ️ This lesson is **one class** on scripting, so we stick to the basics. Blocks marked **ℹ️ Advanced** are optional extras for students who want to go further.
