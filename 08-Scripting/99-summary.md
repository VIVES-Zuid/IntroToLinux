# Summary: Lesson 8 – Shell Scripting

**Concepts**
- Script structure: shebang `#!/bin/bash`, comments
- Making scripts executable & running them (`./script.sh`, PATH)
- Variables, `readonly`, `local`, command substitution `$( )`, arithmetic `$(( ))`
- Arguments: `$0`, `$1`…, `$#`, `$@`, `$?`
- Test conditions: `[ ]` (`-f`, `-d`, `-e`, `-z`, `-eq`, `-lt`, `=`, …)
- Logical operators `&&`, `||`, `!`
- `if` / `elif` / `else` / `fi`
- Loops: `for`, `while`, `until`
- `case` / `esac`
- Functions, exit codes, best practices

**Commands**
- `chmod +x`, `bash script.sh`
- `read` (`-p`), `echo`, `exit`, `return`, `shift`
