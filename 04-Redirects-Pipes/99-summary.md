# Summary: Lesson 4 – Redirects & Pipes

**Concepts**
- Standard streams: stdin (0), stdout (1), stderr (2)
- Output redirection: `>`, `>>`, `2>`, `2>>`, `&>`, `2>&1`
- Input redirection: `<`, here document `<<`, here string `<<<`
- `/dev/null` (discard output)
- Pipes `|` and pipelines; pipe vs redirection
- Named pipes (FIFOs), process substitution `<( )`
- Pipeline exit status (`PIPESTATUS`, `set -o pipefail`)

**Commands**
- Viewing: `cat`, `tac`, `more`, `less`, `head`, `tail` (`-n`, `-f`)
- Text: `sort`, `uniq`, `wc`, `tr`, `grep`, `strings`
- Other: `tee`, `seq`, `mkfifo`
