# Summary: Lesson 5 – Echo, Alias & Operators

**Concepts**
- Whitespace and argument splitting
- Single vs double quotes, escaping with `\`
- Special characters & escape sequences (`\n`, `\t`, colors)
- Command types: builtin, alias, function, external
- Control operators: `;`, `&`, `&&`, `||`
- Exit status `$?`
- Comments `#`, line continuation `\`
- Background jobs

**Commands**
- `echo` (`-e`, `-n`)
- `type`, `which`, `command -v`
- `alias`, `unalias`, permanent aliases in `~/.bashrc`
- `jobs`, `fg`, `bg`, `sleep`
